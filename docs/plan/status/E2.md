# E2 · Xác minh commit phát hành

**14/11/2026** · `codex/hub-next-wip` · [PR #144](https://github.com/unhuman1289/learning-hub/pull/144)

- `/api/health` trả SHA đầy đủ trong `commit`. Trường `version` dùng SHA ngắn ở staging và tag ở production.
- Release staging và workflow GitHub Actions tra lại nhánh và tag trên `origin` trước khi build. Sau deploy, release đối chiếu SHA từ health và chạy smoke test. Production lấy SHA và tag từ checkout phát hành.
- Local đạt 402 test, typecheck, lint, kiểm schema và build cho cả hai môi trường. Đã đối chiếu SHA trong hai cấu hình Worker sinh ra. Git remote mẫu chấp nhận commit từ nhánh hoặc tag đã push, từ chối commit chỉ có local, ref đã bị xoá và checkout bẩn.
- Ngày 14/11, health đang chạy trên cả hai môi trường trả D1 kết nối và nhãn phiên bản cũ. Chờ duyệt #147 và #145 để gộp, triển khai staging và đối chiếu SHA. Production sẽ hiện SHA sau lần phát hành từ checkout production có E2.
