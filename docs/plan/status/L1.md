# L1 · Hợp đồng luyện nghe và chấm chính tả

PR [#158](https://github.com/unhuman1289/learning-hub/pull/158) mở từ `codex/l1-listening-contract` vào `codex/hub-next-wip`.

- Bài v3 nhận đặc tả audio ở mọi dạng câu. Khoá chính tả tiếng Trung cần pinyin số. Sổ CEFR và HSK có thể dùng câu sắp xếp.
- Hub kiểm tra tốc độ, độ dài theo band, tối đa hai câu chính tả và ít nhất một câu nghe có chấm tự động. Lời thoại đi qua bộ lọc quyền riêng tư của đề bài. API bài học chỉ trả metadata âm thanh.
- Chính tả dùng WER và trả từ thiếu, thừa, sai sau khi nộp. Tiếng Trung so theo chữ Hán hoặc âm tiết pinyin. Pinyin có dấu cần ranh giới âm tiết bằng khoảng trắng hoặc dấu nháy khi các âm tiết có thể dính liền. Điểm lưu tối thiểu là 0 theo ràng buộc D1 hiện có.

## Tệp chung đã sửa

- `lib/contracts/lesson-items.ts` thêm nhánh `dictation` trong `answerKey`, được các hợp đồng dùng chung.
- `lib/evidence/autograde.ts` chuyển sang hàm chuẩn hoá dùng chung và chuyển khoá chính tả sang bộ chấm WER. `lib/evidence/submit.ts` gọi bộ chấm khi nộp và lưu lời phê vào cột hiện có.

## Đã chạy trên local

- `npm run contracts:schema`
- `npm run test` đạt 418/418, gồm lưu và đọc kết quả chính tả qua SQLite.
- `npm run typecheck`, `npm run lint`, `npm run contracts:check`, `npm run build` đều đạt.
- Bản build với dữ liệu demo qua Playwright WebKit/iPhone 13 và Chromium/Pixel 7 trả metadata đã lọc, nộp bài thành công và lưu 0,75 điểm kèm từ thiếu.
- Bộ PHONE-CHECK hiện có trên bản sao dữ liệu demo chưa qua bước 3–4 ở WebKit và bước 4 ở Chromium. Kiểm tra trên thiết bị thật còn lại.
