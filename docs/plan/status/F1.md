# F1 — JS bàn học · chưa đạt

Ngày 17/11/2026, cơ sở `461cc607bb9a829e63b37357549d43fc40b01a49`, worktree `codex/f1-desk-js`. Chưa deploy hoặc gộp. Mục tiêu ≤ 150.000 B gzip **chưa đạt**; không giữ các thay đổi thử nghiệm dưới đây.

## Cách đo và phân tích

Build Vinext production, Node 24.11.0; `CI=1 npm run test:e2e:u5 -- --grep 'mở bàn, làm bài'`. U5 đo tổng gzip từng tệp JS được yêu cầu khi mở lại bàn học, sau khi chọn hồ sơ QA, theo `tests/e2e/route-metrics.mjs`; không tính tổng toàn bộ bundle. Cả iPhone 13 WebKit và Pixel 7 Chromium giả lập đều cho cùng số byte. Giá trị F0 177.288 B là số đã báo trước; chạy lại tại đây được **177.294 B**. Không so sánh các byte gzip của từng module như thể chúng cộng chính xác thành kích thước chunk.

Dùng `rollup-plugin-visualizer` 7.1.3, template `raw-data`, `gzipSize: true`, gắn tạm vào môi trường client của Vite; tệp và công cụ nằm ngoài repo. Ba chunk lớn được U5 tải ở nền (kích thước theo U5; tên hash chỉ thuộc build này):

| Chunk | gzip B | Nội dung chính theo visualizer |
|---|---:|---|
| `CoQFJOVd.js` | 67.692 | React DOM client production, React, scheduler, React DOM và JSX runtime |
| `DpW-2WFj.js` | 44.238 | Vinext app-router navigation, navigation planner, app-elements wire, slot, cache busting, history, navigation và error boundary |
| `BXOKv2qR.js` | 31.475 | Vinext browser entry và navigation/history controller; React Server DOM browser client, optimistic routing và browser state |

Ba chunk này cộng 143.405 B. Phần còn lại gồm giao diện bàn học và hook (~13.415 B trong `DM9eMm6x.js`), profile controls (4.093 B), cửa sổ Lübeck (3.699 B), model/route và các chunk nhỏ. Nội dung là kết quả visualizer, kích thước là gzip cả chunk được U5 tải.
