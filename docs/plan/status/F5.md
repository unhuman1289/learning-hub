# F5 — đo vị trí Worker staging

## Chạy E2E thủ công

Trong GitHub, mở **Actions → Learning Hub CI → Run workflow**, chọn nhánh cần kiểm tra rồi chọn **Run workflow**. Có thể bật `e2e_diag` để lưu artifact chẩn đoán trong bảy ngày. Lệnh tương đương: `gh workflow run ci.yml --ref <tên-nhánh>`; thêm `-f e2e_diag=true` nếu cần chẩn đoán.

Job `checks` chạy với mỗi push, pull request và lần gọi tay. Job `e2e` chạy khi gọi tay hoặc khi pull request có nhãn `e2e`; thêm nhãn cũng tạo một lượt CI mới. Container dùng Playwright 1.65.1, tương ứng `@playwright/test` trong lockfile; cập nhật cả tag container khi nâng phiên bản đó.
